# 🎓 Convite de Formatura Digital — CPM

Um convite de formatura interativo, elegante e totalmente personalizado, criado com **HTML, CSS e JavaScript**.  
Desenvolvido para proporcionar uma experiência única e emocionante aos convidados.

---

## 💡 Sobre o Projeto

Este convite foi desenvolvido com o objetivo de unir **emoção, tecnologia e design** em uma apresentação moderna e acessível.  
Cada detalhe — da música à animação — foi pensado para representar a **história, os valores e as conquistas** do formando.

---

## 🧰 Tecnologias Utilizadas

- **HTML5** — Estrutura do convite  
- **CSS3** — Estilo e animações  
- **JavaScript** — Lógica, personalização e música  
- **GitHub Pages** — Hospedagem gratuita do projeto  

---

## ⚙️ Personalização

Cada formando pode editar facilmente seu convite alterando:
- 🎵 Música
- 👤 Nome
- 📝 Texto da carta
- 🖼️ Foto

Essas informações podem ser configuradas diretamente no arquivo `config.js`.

---

## 🚀 Como Visualizar o Convite

1. Clique no link abaixo para acessar a página:
   👉 [Acessar Convite](https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO)

2. Para criar seu próprio convite:
   - Baixe o repositório (`Code → Download ZIP`)
   - Edite o arquivo `config.js` com suas informações
   - Suba no GitHub com um novo nome de repositório
